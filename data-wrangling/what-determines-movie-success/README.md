# What Determines Movie Success?

## Overview

This project examines factors associated with movie performance by combining and cleaning data from multiple sources.

The goal is to explore how characteristics such as budget, genre, popularity, audience response, and revenue relate to movie success.

## Analysis

The project includes:

- Combining data from multiple sources
- Cleaning and standardizing fields
- Handling missing and inconsistent values
- Transforming variables for analysis
- Comparing movie budgets and revenue
- Examining genre and popularity patterns
- Exploring audience response and ratings

## Tools

- Python
- Pandas
- Jupyter Notebook
- APIs
- Data cleaning and transformation techniques

## Project Files

- Jupyter notebook — data collection, cleaning, integration, and analysis
- Supporting project documentation

## Reproduce the Analysis

Place `cleaned_website_movies.csv` and `cleaned_api_movies.csv` beside the notebook, and `cleaned_flat_movies.csv` in its parent directory (`data-wrangling/`). These are cleaned inputs from earlier preparation stages and are not included. Use Python, pandas, Matplotlib, requests, and SQLite (Python standard library).

Open Jupyter from this project folder and restart the kernel before running all cells in order. Original source data is not bundled in this repository. See [validation status](../../docs/validation.md) for the current execution limits. Existing code, markdown, and saved outputs in the notebook are preserved.
