## Repository Conventions

Folders use lowercase domain or method names separated by hyphens. Artifact filenames use descriptive lowercase words separated by underscores. Preserve final artifacts; move superseded versions into a clearly labeled archive only when a replacement is established. No files were discarded in this cleanup.

Each project README explains its problem, approach, artifacts, and limitations. Source datasets and credentials are not bundled. Run notebooks from their project directory. See the [validation record](docs/validation.md), [rename record](docs/file-renames.md), and [portfolio readiness](docs/portfolio-readiness.md) before interpreting saved outputs as a reproducibility guarantee.
