# Lord of the Rings Wikipedia RAG Study

A supporting study that retrieves text from a Wikipedia article, embeds chunks, indexes them with FAISS, and uses retrieved context with a sequence-to-sequence language model.

[Open notebook](lord_of_the_rings_rag.ipynb)

Run in a compatible Jupyter or Colab environment with internet access. The notebook installs its packages and downloads external model weights. Article content and external dependencies may change. The original Colab badge inside the preserved notebook points to its former path; open this current file directly instead.

This supporting study is separate from the ten selected portfolio entries. Execution has not been confirmed in this environment.
